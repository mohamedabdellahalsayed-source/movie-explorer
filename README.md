# 🎬 Movie Explorer

A movie and TV show discovery app built with React, Vite, and Tailwind CSS, powered by the TMDB API.

## 🔗 Live Demo
[movie-explorer-ecru-beta.vercel.app](https://movie-explorer-ecru-beta.vercel.app)

## ✨ Features
- Search for movies and TV shows
- View detailed movie info (rating, overview, backdrop)
- Save favorites (persisted with localStorage)
- Responsive design with Tailwind CSS

## 🛠️ Built With
- React
- Vite
- Tailwind CSS
- React Router
- TMDB API
